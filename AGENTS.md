# Pencil design direction

All current and future tools in this repository should share the established blue-violet theme. Use near-black plum backgrounds, darker violet panels, muted violet primary accents, restrained darker cool-blue secondary accents, and readable muted royal-blue text. Use subtle blue-to-violet gradients for primary actions. Keep the colors calm, readable, and consistent with the home page and COOP tool; avoid saturated neon backgrounds. Preserve responsive layouts, visible focus states, and readable text contrast.

Keep each tool in its own folder and link it from the main tools directory. Maintain the user-requested empty README unless asked to populate it.
