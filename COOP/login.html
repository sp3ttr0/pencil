What does this demonstrate?

If the checker reports “Redirect confirmed,” the opened target tab was successfully redirected here using the retained window handle.

That confirms navigation access during this test. It does not by itself establish account compromise or identify the target’s COOP header. Opening this page directly is not a test result.

Security header to check

Cross-Origin-Opener-Policy may be missing or configured permissively. This test observes navigation behavior; it does not read the target’s response headers, so a missing header is not confirmed.

Recommended setting for strict opener isolation:

Cross-Origin-Opener-Policy: same-origin

Set this as an HTTP response header on the target’s HTML documents. A missing header defaults to unsafe-none. Check the final document response in browser DevTools → Network → Headers to verify the actual value. Test OAuth, payment, and other popup integrations before deployment because strict isolation can break window communication.
